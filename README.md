# AI余额桌宠

常驻 Windows 桌面的小挂件，一抬眼就能看到大模型平台的余额 / 配额，目前仅支持 Windows 操作系统。

三种模式，切换后人物贴图、气泡配色和各自的配置会一起换：

|  | DeepSeek | GLM Coding Plan | 纯桌宠模式 |
|---|---|---|---|
| 气泡主数字 | 现金余额（¥） | 5 小时窗剩余百分比 | 不显示（只冒台词） |
| 气泡提示行 | 今日已用 | 周配额已用百分比 | — |
| 峰谷显示 | 峰/谷 + 倒计时（工作日 9–12、14–18 为高峰） | 峰/谷 + 倒计时（工作日 14–18 为高峰，其余含周末全天为谷） | 不显示 |
| 需要填 | API Key（`sk-xxxx`） | Coding Plan 令牌 | **不需要任何凭据** |
| 额度提醒 | 余额低于阈值、今日预算 | 5 小时窗 / 周窗剩余低于 20% | — |

不需要装 DSH 或任何宿主环境。

## 怎么用

| 操作 | 效果 |
|---|---|
| **左键点角色头旁的蓝色按钮** | 开 / 关设置菜单——**这是菜单唯一的入口**。按钮只在鼠标悬停在角色上时显形 |
| **左键点角色** | 弹出气泡：DeepSeek / GLM 显示余额或配额，纯桌宠模式只冒一句台词 |
| **左键点气泡** | 换成随机台词或动图（内容可在菜单里自己编排） |
| **按住拖拽** | 拖到桌面任意位置，靠近四边会吸附，吸到左边会整体镜像翻转 |
| **右键托盘图标** | 显示 / 隐藏、打开配置文件、退出 |
| **点角色以外的地方** | 事件穿透到桌面，不影响你正常用电脑 |

## 菜单里能调的

- **模型配置**（最上方）：切换 DeepSeek / GLM / 纯桌宠模式；旁边一行填**当前模式的凭据**
  （DeepSeek 填 API Key，GLM 填 Coding Plan 令牌——原样粘贴，**不要加 `Bearer` 前缀**；
  纯桌宠模式这一行会隐藏）。各模式的凭据分开存，互不覆盖
- **角色**：导入任意图片当角色（PNG / GIF / APNG，带裁剪与动图窗口）、置顶、删除。
  **「当前用哪个角色」按模式各记一份**；「默认角色」= 该模式自带的贴图
- **大小 / 音量 / 音效**：音效可自定义（见下）
- **气泡**：全局开关 + **自定义泡泡**（点击序列编辑器，见下）
- **每轮消耗提示**：开关、自动关闭秒数、内容都可改
- **吸附与翻转**、**隐藏菜单按钮**、**避让滚动条**
- **资源管理**：角色、音频片段/音效组、泡泡图片的统一管理入口
- **自动冒泡**：每隔一段时间主动说一句（关闭 / 5 / 15 / 30 分钟 / 1 / 2 小时）
- **开机自启**
- **小鲸鱼记账**（仅 DeepSeek 模式）：用量记录、余额预警、今日预算

## 可自定义的内容

- **泡泡点击序列**：第 1 击、第 2 击……想显示什么自己排；支持「并列泡」（A/B 两泡按权重二选一）
  与模块化排版——文本、余额、今日已用、峰谷时段、时段倒计时、随机语句、图片/动图、随机图片、超链接。
  编辑器里可拖拽排序、逐行调字号/字重/颜色/底色，并带真实预览
- **随机语句**：按模式分池。调色板提供「随机语句-deepseek」「随机语句-GLM」
  「--桌宠模式随机语句--」，池子 = 通用句 + 该模式专属句；句子和权重都能自己增删改
- **角色**：任意图片（含动图），按模式各记一份
- **音效**：上传音频片段、自由组合「按下 / 松开」两个槽位（留空即该事件静音）、置顶
- **泡泡图片**：上传自己的配图，供「图片 / 随机图片」模块引用
- **提醒文案**：余额预警、今日预算、每轮消耗提示都可在编辑器里排版（文字 + 图片 + 链接）
- **自定义 API 模型**：DeepSeek 之外的厂商（OpenRouter、Kimi、GLM Coding、火山方舟、
  Ollama…30+ 家模板）可配余额接口 / 订阅额度 / 单价，支持测连通性、按模型设提醒与额度

## 功能

- 余额 / 配额展示，60 秒自动刷新，点角色可手动刷新，数字有滚动动画
- 今日已用（按余额差值本地记账，跨天归档）
- 三模式切换，人物贴图与气泡配色随模式变化，**各模式的配置互相独立**
- 峰谷时段提示与倒计时（各模式按自己的规则计算）
- 随机台词、动图、按压音效、Q 弹反馈
- 拖拽 + 四边吸附 + 左吸附镜像翻转，位置记忆
- 窗口置顶且点击穿透，不挡桌面操作

## 安装

### 发行版

到 [Releases](https://github.com/AngleCatAy/AI_pets/releases) 下载 zip → 解压 → 双击 `DeepSeekPet.exe`。

第一次打开时角色会出现在桌面右下角。填 Key 的方法：

1. 把鼠标移到角色身上，头部一旁会出现一个菜单按钮
2. 左键点它打开菜单，最上方是「模型配置」——在这里选模式、填当前模式的凭据
3. 填进去按回车（或点别处）立即生效

不想填任何 Key 也可以：把模式选成 **`--纯桌宠模式--`**，它就只是一只桌宠。

DeepSeek 的 Key 在 https://platform.deepseek.com/api_keys 申请；GLM 用的是 Coding Plan 的令牌，
**原样粘贴、不要加 `Bearer` 前缀**。

### 从源码跑

```cmd
npm install          :: 只需一次。桌宠模式要 Electron，浏览器标签页模式不需要
start-pet.cmd        :: 桌宠：出现在桌面右下角
start.cmd            :: 或者只要浏览器标签页模式
```

## 配置

打包版把配置放在 `%APPDATA%\ds-pet\config.json`；源码运行则放在项目根目录的 `config.json`
（可复制 `config.json.example` 改）。**推荐使用桌宠自带菜单填入**。

| 字段 | 必填 | 说明 |
|---|---|---|
| `apiKey` | 否 | DeepSeek 的 API Key |
| `providers.glm.planToken` | 否 | GLM Coding Plan 令牌（原样粘贴，**不要加 `Bearer` 前缀**） |
| `platformToken` | 否 | `platform.deepseek.com` 的网页会话令牌。早期版本的「实时·令牌」用量统计需要它，现在记账是唯一方式，**一般不需要** |

也可以用环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_PLATFORM_TOKEN` / `GLM_PLAN_TOKEN`，优先级高于配置文件。

除凭据外的设置（大小、音效、气泡序列、角色、自动冒泡等）都存在
`data/` 与 `%APPDATA%\ds-pet\` 下，**大部分按模式各存一份**，在菜单里改即可，不必手编文件。

## 已知限制

- 窗口是**置顶**的，会浮在全屏视频 / 游戏之上；不想要时右键托盘 → 隐藏
- **只覆盖主显示器**的工作区，多显示器下角色只能在主屏活动
- 「每轮对话消耗」需要额外一层本地反向代理才能自动上报，目前接口已就绪但默认不启用
