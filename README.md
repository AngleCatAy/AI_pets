# 小鲸鱼余额桌宠（不依赖 DSH）

DeepSeek 余额挂件的独立运行版，两种形态：

- **桌宠模式**（默认推荐）：真·桌面上的透明置顶小鲸鱼，左键交互、右键设置，不在浏览器里
- **浏览器标签页模式**：一个本地网页，内容与 DSH 插件版一致

原版 [MeteorNOX/DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 是 DSH（DeepSeek Harness）的插件包，必须挂在 DSH Web 界面里才能跑。这个版本把宿主侧换成了自带的本地 Node 服务，不需要装 DSH、不需要 pnpm。

## 快速开始

```cmd
:: 1. 装依赖（只需一次；桌宠模式要 Electron，标签页模式不需要）
npm install

:: 2. 启动
start-pet.cmd     :: 桌宠：小鲸鱼出现在桌面右下角
start.cmd         :: 或浏览器标签页模式
```

API Key 直接在**挂件菜单最底部那一行**填（见下面「桌宠模式怎么用」）。想先手写配置文件也行：复制 `config.json.example` 为 `config.json`，把 `apiKey` 填成你的 `sk-xxxx`，地址在 https://platform.deepseek.com/api_keys 。

## 桌宠模式怎么用

| 操作 | 效果 |
|---|---|
| **左键点蓝色按钮** | 开 / 关设置菜单——**这是菜单唯一的入口**。按钮**只在鼠标悬停在角色上时显形**（带白描边），鼠标离开角色就隐藏，位置在角色头部一侧 |
| **左键点鲸鱼** | 弹出气泡：DeepSeek 显示余额+今日已用；**GLM 显示 5 小时窗剩余% + 周配额已用%** |
| **左键点气泡** | 切换成随机台词（时段提示、怪话、动图等，加权随机），再点关闭 |
| **按住拖拽** | 把鲸鱼拖到桌面任意位置，靠近四边会吸附，吸到左边会整体镜像翻转 |
| **右键** | 不做任何事（按设计，避免出现第二条进菜单的路） |
| **右键托盘图标** | 显示隐藏、打开配置文件、退出 |
| **点鲸鱼以外的地方** | 事件穿透到桌面，不影响你正常用电脑 |

菜单里除了挂件原有的那些，还有几行桌宠侧的：

- **菜单按钮位置**：它在角色头部一侧（左吸附镜像后落在左边）。**平时是隐藏的，只有鼠标悬停在角色上（或直接移到按钮所在的那一小块）才显形**——这是上游原本的行为，刻意保持，免得按钮一直挂在角色头上；显形时带白描边，压在黑头发这类深色贴图上也能看见。
  ⚠️ 这里踩过一个上游 bug：挂件有个「点击落在贴图不透明像素上就拦截 click」的保护（`onDocClickStopper`，本意是防止点击穿透到下层页面），而菜单按钮**正好压在贴图上**。鲸鱼贴图时按钮那块恰好透明所以一直正常；换成 GLM 贴图后按钮压在黑头发上，点击被整片吞掉，表现为"按钮点不动"。补丁里已给 `.dshwv-menu-btn` / `.dshwv-menu` 放行。
- **模型**：切换 DeepSeek / GLM（折叠栏，和 API Key 一样默认收起，点标题行展开）。GLM 走 Coding Plan 配额接口，气泡显示「5 小时窗剩余% + 周配额已用%」，时段提示按 GLM 规则（高峰=工作日 14:00–18:00，其余含周末全天为谷，谷期积分五折）。需要先在 `config.json` 填 `providers.glm.planToken`。切换后气泡会先显示「加载中…」再翻到新厂商的数据（拉接口有 1–2 秒延迟）
- **自动冒泡**：每隔一段时间主动弹一句随机台词（关闭 / 5 / 15 / 30 分钟 / 1 / 2 小时），默认关闭
- **开机自启**：写进系统启动项
- **API Key**：最底下，做成折叠栏——已配好时收起成 `▶ API Key`，点标题行展开。DeepSeek 的 key 在这里填；GLM 的令牌目前直接改 `config.json`。

> 「左键点气泡」这条要注意：气泡只有**画出来的那部分**能点（原版 CSS 用的是
> `pointer-events:visiblePainted`），点到气泡外的透明区仍然是穿透到桌面。

退出方式：右键鲸鱼 → 退出桌宠，或右键任务栏托盘的小鲸鱼图标 → 退出。

### 三个桌宠独有的设置

「自动冒泡」「开机自启」「API Key」是桌宠侧新增的，原版挂件菜单里没有。它们**并进了挂件自带的那套菜单最底部**（API Key 是最后一行），这样设置只有一处，不会出现两套菜单内容对不上。

实现上分两半：

- **画控件**靠 `tools/sync-upstream.mjs` 的补丁表，在 `menuBox` 上追加三行。补丁只在检测到 `window.__dsPetHost`（即桌宠窗口）时才添加，浏览器标签页模式不会出现点了没用的控件。
- **读写真值**靠 Electron 主进程——自动冒泡的间隔存在服务端配置里、开机自启在系统启动项里、API Key 在配置文件里，挂件自己都不知道。页面加载完主进程会把真实值推给它（`window.__dshWhalePetSettings`）用于回显；控件变化时通过 `__dsPetHost.setAutoPop / setOpenAtLogin / setApiKey` 转回主进程落地。API Key 保存后主进程会立刻触发一次余额刷新，日志里只记长度、不记内容。

自动冒泡调用的是挂件内部暴露的 `window.__dshWhaleApi.showRandomLine()`——原版这条路径只能由用户点击气泡触发，而随机台词段、加权抽签、气泡动画都是闭包内的私有状态，所以补丁只开了这一个最小口子。

### 实现方式

窗口不是"包住鲸鱼的小窗"，而是**覆盖整个工作区、透明、置顶、默认整窗穿透点击**的一个窗口，鲸鱼只是画在其中右下角的挂件。

这么做是因为挂件前端**本来就是**为"覆盖在界面之上但不挡操作"设计的——它内置了鲸鱼 PNG 的 alpha 命中测试和透明区穿透意图（原版注释里就写着"保持透明区 pass-through"）。桌面于是变成了它的"视口"，拖拽、四边吸附、点击刷新、按压音效、Q 弹反馈**全部保持原版行为，零改动**。

`pet/adapter.js` 只补三件挂件本身不该管的事：

1. **点击穿透**：鼠标移动时做鲸鱼像素级 alpha 判定，不在鲸鱼上就调 `setIgnoreMouseEvents(true, {forward:true})` 让事件穿到桌面。按住鼠标期间强制保持可交互——否则快速拖拽时鲸鱼有 transition 动画会落在光标后面，按像素判定会中途"丢失"命中，导致 `pointerup` 收不到、鲸鱼卡住。
2. **菜单**：**只有一条入口——左键点鲸鱼旁边的蓝色按钮**。右键刻意不绑定任何动作（`adapter.js` 里不注册 `contextmenu`，也不 `preventDefault`），托盘里也没有"打开设置菜单"的捷径，这些都是为了不让设置界面出现第二条路。`tools/check-wiring.mjs` 会检查这两点，防止以后被顺手加回去。
3. **设置落地**：菜单里挂件原有的控件由挂件自己处理并持久化；桌宠侧那三行（自动冒泡 / 开机自启 / API Key）通过 `__dsPetHost.*` 转给主进程落地，主进程再把真值推回来回显。气泡能被点到，靠的是 `overBubbleShape()` 里用 `elementFromPoint` 复用浏览器自己的命中测试——气泡开着时 SVG 形状是 `pointer-events:visiblePainted`，`elementFromPoint` 正好只返回画出来的部分。

#### 菜单里有输入框，所以窗口要临时可聚焦

窗口默认 `focusable: false`，好处是点鲸鱼不会把你正在用的应用抢走焦点。但**那种窗口永远拿不到键盘焦点**——菜单最底部的 API Key 输入框就会完全打不进字（而且不报错，纯粹静默失效）。

所以 `adapter.js` 用 MutationObserver 盯着菜单的开合，菜单一开就通知主进程 `setFocusable(true)` **并 `win.focus()`**，菜单一关再切回 `false`。两点都别省：只改 focusable 不够，实测窗口仍然拿不到前台，必须显式 focus 一次。

另外输入框聚焦时会全选已有内容——否则用户直接打字会把新 Key 插进旧 Key 中间，拼出一个坏值（实测踩到）。

API Key 那一栏是**折叠式的**：收起 `▶ API Key`，展开 `▼ API Key` 且输入框在下一行；点标题那一行切换。两个细节是踩出来的：

- **三角用 CSS 边框画，不用 `▶`/`▼` 字符**。字符三角在 Windows 上可能被渲染成 emoji（变成彩色方块），而且尺寸只能靠字号间接控制——上一版用了字符版，被反馈太小。
- **开合目标放在标题整行，不只放三角**。三角本身才十来像素，实测连程序化点击都很难命中，真实鼠标只会更别扭。

开合状态只看 `apiKeyInput.style.display`，开关都是自己设的，不依赖挂件内部状态。

### 已知限制

- **窗口是置顶的**，会浮在全屏视频/游戏之上。目前没有做"检测到全屏应用自动隐藏"。不想要的话可以右键托盘 → 显示/隐藏。
- **只覆盖主显示器的的工作区**，多显示器下鲸鱼只能在主屏活动。
- **每轮对话消耗统计还没接**（见下）。

## 配置

`config.json`：

| 字段 | 必填 | 说明 |
|---|---|---|
| `apiKey` | 是 | DeepSeek API Key，拉取余额用 |
| `platformToken` | 否 | `platform.deepseek.com` 的网页会话令牌。只有把用量模式切到「实时·令牌」才需要，留空则该模式自动回落到小鲸鱼记账 |
| `host` | 否 | 默认 `127.0.0.1`，只监听本机 |
| `port` | 否 | 默认 `3080` |

也可以用环境变量 `DEEPSEEK_API_KEY` / `DEEPSEEK_PLATFORM_TOKEN`，优先级高于配置文件。
改完 `config.json` 不用重启服务，下次请求就会重新读取。

## 多厂商（v2.0）

v2.0 起支持切换模型厂商，目前已接 **DeepSeek** 和 **GLM Coding Plan**：

| | DeepSeek | GLM Coding Plan |
|---|---|---|
| 主显示 | 现金余额（¥） | 5 小时窗剩余百分比 |
| 次显示 | 今日已用（记账/令牌） | 周配额已用百分比 |
| 时段规则 | 工作日 9–12、14–18 为峰 | 工作日 14:00–18:00 为峰，其余含周末全天为谷（谷期积分五折） |
| 凭据 | `apiKey`（API Key，Bearer） | `providers.glm.planToken`（裸 token，无 Bearer） |

在菜单「模型」行切换，切换后**人物贴图和气泡配色也会跟着换**：

- **贴图**：GLM 用 `assets/personas/glm/character.png`，DeepSeek 用 `assets/DSniang1.png`。按当前厂商由服务端出图（前端始终访问同一个 `/dsh-whale/image.png`，所以换皮对挂件透明）。左吸附时的镜像翻转是挂件原有逻辑，换皮后自动适用
- **配色**：GLM 走黑色系（正文 `#1c1c1c`、气泡描边黑、提示行灰），DeepSeek 保持原来的藏青 `#203170`。**峰谷的绿/红不受影响**——那两个颜色是台词的行内样式，优先级高于主题表
- 换贴图时会**重建点击命中遮罩**（遮罩是从图片 alpha 现场算的，不重建的话点击判定还按旧角色轮廓走）
- **气泡首行文案**：GLM 显示 `GLM余额`（主数字是 5 小时窗剩余百分比），DeepSeek 显示 `DeepSeek 余额`
- **时段台词也按厂商分**：点气泡后那句「当前时间段为:」，GLM 固定显示 `空闲时段`（绿）/ `高峰时段`（红），**不再带「周配额已用」那一行**；菜单里 `梁文峰谷 / !?强强?!` 那套趣味文案**只作用于 DeepSeek**（DeepSeek 的时段气泡照旧保留「今日已用」行），不跨模型
- **GLM 下有两项设置变灰**：菜单里的「用量」和「峰谷」目前只对 DeepSeek 有意义（记账/令牌、梁文峰谷文案），GLM 模式下这两行**变灰且点不动**。注意是**只禁用、不改值**——切回 DeepSeek 立刻恢复你原来选的项。除此之外，**切换厂商不会动任何其它设置**（大小 / 音效 / 音量 / 气泡 / 每轮消耗 / 避让滚动条 / 自动冒泡都原样保留）
- **GLM 暂时不说怪话、也不放动图**：怪话台词组和动图都是 DeepSeek 的素材（`rua.gif` 就是那只鲸鱼），两者都在 GLM 下被整组跳过——所以 **GLM 点气泡只会看到时段提示这一种**。以后要加 GLM 专属台词池，按同一套 `ds: true` 标记方式加组即可

配色表在 `tools/sync-upstream.mjs` 的 `applyProvider` 补丁里。`assets/personas/` 目录结构就是给后续更多厂商留的。

GLM 的配额接口（`/api/monitor/usage/quota/limit`）来自官方插件
[zai-org/zai-coding-plugins](https://github.com/zai-org/zai-coding-plugins) 的实现，认证方式照抄（注意没有 Bearer 前缀）。
拿到真实响应结构可以用 `node tools/probe-glm.mjs` 随时复核。

### 随机台词池怎么调

点气泡（或自动冒泡）时，从挂件里的 `RANDOM_GROUPS` **按 `w` 权重抽一组**，组内再用 `pickOne` **等概率抽一句**。所以：

- 想改**某一类台词的总频率** → 调那一组的 `w`（总权重变了，各组占比会自动重新分配）；
- 想改**组内某一句的概率** → `pickOne` 是等概率的，只能靠「把那句多写几遍」来加权，或者把它单独拆成一组、单独给 `w`；
- 标了 `ds: true` 的组只在 DeepSeek 模式下参与抽签（GLM 下整组跳过，剩下的组会重新归一化）。

这份数组和 `pickRandomLines()` 都在 `tools/sync-upstream.mjs` 的补丁表里，改完**必须**重跑 `node tools/sync-upstream.mjs` 重新生成 `lib/widget.js`（别直接改生成物）。

### 关于「每轮对话消耗」

这一项在原版里是从 DSH 的会话事件流里读精确 usage 的，脱离 DSH 后没有等价数据源。
服务端已经把接口和结算逻辑准备好了（`POST /dsh-whale/report-turn`，带 `turn`/`model`/`inputTokens`/`cacheReadTokens`/`outputTokens`/`reasoningTokens`），
缺的只是一层本地反向代理：把客户端的 `base_url` 指向本地代理，代理转发到 `api.deepseek.com`，从每个响应里读出 `usage` 后调用上面这个接口。

在代理接上之前，该功能会安静地不显示，不影响其它功能。

## 目录结构

```text
ds_pet/
├── start.cmd / start-pet.cmd  # 双击启动：浏览器标签页 / 桌面桌宠
├── server.js              # 本地服务：余额、记账、定价、路由；也可被主进程内嵌
├── index.html             # 标签页模式的页面
├── pet.html               # 桌宠模式的页面（透明背景）
├── lib/
│   └── widget.js          # 挂件前端本体（自上游 WIDGET_JS 抽取，见下）
├── pet/
│   ├── main.cjs           # Electron 主进程：内置服务、透明置顶窗口、托盘、菜单入口、API Key 读写
│   ├── preload.cjs        # 桌宠窗口的受限 IPC 桥
│   └── adapter.js         # 页内适配器：点击穿透、设置转发、点击诊断
├── assets/                # 鲸鱼图、gif、音效（来自上游，MIT）
├── tools/
│   ├── start.ps1          # 启动器逻辑（环境检查、拉起服务、打开界面）
│   ├── sync-upstream.mjs  # 从上游同步 widget.js
│   ├── check-wiring.mjs   # 检查页面/桥/IPC 的接线是否一致
│   └── package.mjs        # 打包免安装版
├── dist/                  # 打包产物（已在 .gitignore 里）
├── data/                  # 开发态运行时数据；打包后改用用户目录
├── config.json            # 你的配置（已在 .gitignore 里）
└── _ref/index.js          # 上游源码缓存，供同步脚本比对
```

## 打包发给别人

```cmd
:: 国内网络必须挂镜像：packager 要取 Electron 的校验文件（SHASUMS256.txt），
:: 不挂就会去连 github.com 然后超时/ECONNRESET，直接打包失败
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
npm run package
```

产出 `dist/DeepSeekPet-win32-x64/`，整个文件夹压缩后发给对方即可——**他不需要装 Node，也不需要装 Electron**，解压双击 `DeepSeekPet.exe` 就跑。压缩后约 150MB（体积基本全是 Electron 运行时，我们的代码不到 1MB）。

朋友第一次打开时，小鲸鱼会直接出现在桌面右下角，气泡里提示"未配置"——把鼠标移到鲸鱼上、左键点右上角的蓝色按钮，菜单最底部那一行就能填 API Key（填进 `%APPDATA%\ds-pet\config.json`），不用他去改 JSON。包里还会自动生成一份 `使用说明.txt`。

### 为打包做的三处调整

1. **服务内置进主进程**。原来桌宠是两个进程：启动器先起 `node server.js`，再起 Electron，这依赖系统里的 Node。现在主进程直接 `import('../server.js')` 把服务跑在自己进程里，所以对方零依赖。`server.js` 因此改成了可嵌入形式（导出 `configure()` / `startServer()`），只有在被直接 `node server.js` 运行时才自己监听端口。顺带修了一个隐患：嵌入时端口冲突不能再 `process.exit`——那会把整个桌宠干掉，现在改成返回错误交给主进程决定。
2. **配置和运行数据改到用户目录**。打包后安装目录可能只读、升级还会被覆盖，所以配置、尺寸记忆、记账账本、日志都放 `app.getPath('userData')`；开发态仍然放在项目里，方便查看和手改。
3. **API Key 改成在菜单里填**。原先有一个独立的"首次运行引导窗口"，现在去掉了——Key 直接是菜单最底部的一行。少一个窗口、少一套 preload/IPC，也不用在启动流程里判断"是不是第一次"。代价是没配 Key 时只有气泡里那句"未配置"提示，得知道去点蓝色按钮（`使用说明.txt` 里写了）。

### 为什么用 @electron/packager 而不是 electron-builder

electron-builder 出安装包还要另外下载 NSIS / winCodeSign 之类的二进制，国内网络容易卡住（这个项目在装 Electron 本身时就已经踩过一次，得挂 npmmirror 镜像）。packager 直接用已经装好的 Electron，不额外下载任何东西。产物是个文件夹而不是单文件安装程序，但压缩后发给朋友用起来没差别。

打包时 `config.json` **是硬性排除的**——里面有使用者自己的 API Key。`tools/package.mjs` 里还会做一次检查：如果发现配置里有 Key，会明确提示它不会被打进包里。

想改成单文件安装程序（NSIS）或加图标、改版本号，再上 electron-builder 也可以，那属于分发形式的升级，不影响应用本身。

## 排查

桌宠不出现或行为异常时，先看日志：

```cmd
:: 桌宠把启动、窗口尺寸、设置写入、右键菜单、点击诊断都记在这里
type data\pet.log

:: 想看穿透判定的实时明细（光标位置 + 是否命中鲸鱼）
set DS_PET_DEBUG=1
start-pet.cmd
```

日志里跟交互有关的几行值得留意：

- `菜单按钮位置 4,1173 尺寸 26x26（窗口坐标）` —— 启动时记一次菜单入口坐标。菜单只有这一条入口、按钮又只有 26×26，找不到入口时可以拿它比对。
- `菜单已开：菜单框 …；API Key 输入框 …` —— 菜单打开时才准的坐标（菜单关着时它的 rect 是未定位的静态值，别拿那条）。
- `窗口可聚焦 -> 开/关 … isFocusable=` —— 菜单开合时窗口是否成功切成可聚焦。如果输入框打不进字，先看这行是不是一直没变。
- `已更新 API Key（长度 N）` —— 只记长度、不记内容。
- `左键点击鲸鱼：位移 Npx（按点击处理 / 按拖拽处理，不会弹气泡）` —— 挂件把按下到抬起位移超过阈值的操作当成**拖拽**（走吸附），那样就不弹气泡，看起来像"点了没反应"。上游原本的阈值只有 3px，真实鼠标很容易抖过，已放宽到 10px（见补丁表）。

另外：窗口默认整窗穿透，**只有指针在鲸鱼像素上时才开始接收点击**。所以如果启动瞬间光标本来就停在鲸鱼上，需要先动一下鼠标才会生效——这一条已经用「启动时把光标位置推给页面」修掉了。

浏览器标签页模式要看服务日志，直接 `npm start` 前台运行即可。

## 同步上游更新

挂件前端 `lib/widget.js` 不是手写的，而是从上游 `lib/index.js` 里的 `WIDGET_JS` 抽取出来的：

```cmd
node tools/sync-upstream.mjs           # 用本地缓存的上游副本
node tools/sync-upstream.mjs --fetch   # 先重新下载上游再抽取
```

上游把整个前端放在一个模板字符串里，脚本是**取它的运行时求值结果**，不是切片源码文本。
两者不等价：源码里有转义（例如 `.join('\\n')` 求值后是真换行），照抄源码会让 CSS 规则之间
用字面 `\n` 分隔，浏览器错误恢复时会把那个 `n` 粘到下一个选择器上，导致除第一条外所有样式失效。

脚本还维护一份有记录的补丁表，目前 **25 处**（实际数量以脚本运行结束打印的 `补丁数` 为准）：

| 补丁 | 条数 | 原因 |
|---|---|---|
| 菜单里的 `实时·令牌 (用法：去问dsh)` → `(需填平台令牌)` | 1 | 独立版没有 dsh，文案改指向 `config.json` |
| 末端追加 `window.__dshWhaleApi`（`showRandomLine` / `isBubbleShown` / `applyProvider`，`applyProvider` 里还负责把 GLM 下不可设的两行变灰） | 1 | 自动冒泡需要从外部触发随机台词；并按厂商调整菜单可用性 |
| `var CLICK_SQ = 9` → `100` | 1 | 3px 的点击/拖拽阈值太紧，真实鼠标的轻微抖动会让左键点击被当成拖拽而"没反应" |
| `menuBox` 追加桌宠侧设置行（自动冒泡、开机自启、模型、API Key 折叠栏 + `__dshWhalePetSettings`） | 1 | 桌宠侧设置并入挂件自带菜单 |
| 多厂商 v2.0：加 `applyProvider` 调用、`provider`/`providerLabel`/`usageLabel` 数据驱动、百分比显示、`render()` 同步标签 | 8 | 支持 DeepSeek ↔ GLM 切换，换贴图/换配色，气泡文案随厂商变 |

| 多厂商 v2.0：台词组标 `ds: true` + `pickRandomLines()` 按厂商过滤抽签池 | 6 | GLM 暂时没有自己的台词池：DeepSeek 的怪话与动图都不该在 GLM 下出现 |

### 启动脚本的写法约束

两个 `.cmd` 都**只做纯 ASCII 转发**，全部逻辑和中文提示放在 `tools/start.ps1` 里。这不是绕远路，而是必须的：

- `cmd.exe` 不会因为批处理文件里执行了 `chcp 65001` 就按 UTF-8 重新读取自身，文件里的中文会被按当前代码页错误解码，甚至泄漏成非法命令。所以 `.cmd` 里不能放中文。
- 反过来，`tools/start.ps1` **必须保存为 UTF-8 with BOM**，否则 Windows PowerShell 5.1 会按 ANSI 解码，中文变乱码并可能直接解析失败。
- `.cmd` 必须用 **CRLF** 换行，否则 `for /f` 之类的语句会被错误解析。
